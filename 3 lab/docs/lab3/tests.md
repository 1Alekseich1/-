# Проверка ЛР 3

1. Каталог содержит 40 книг; можно увидеть счётчик.
2. Ввести «ТОЛСТОЙ» — поиск без учёта регистра.
3. Выбрать «Антиутопия», включить «только доступные» — «1984» исчезнет.
4. Переключить три варианта сортировки.
5. Ввести `несуществующий автор` — появляется сообщение пустого списка.
6. Нажать сброс — все фильтры очищаются.
7. Добавить 2 книги, открыть «Мой список», затем обновить страницу; записи останутся.
8. Удалить одну книгу из списка; счётчик уменьшится.
9. Проверить `aria-pressed` у кнопки в DevTools.
10. DevTools → Application → Local Storage → изменить `booknest.lab3.v1` на `сломано` → обновить: сайт не падает.
11. DevTools → Console: ошибок быть не должно.
12. ESLint — запустить `npm install`, затем `npm run lint`.

Для отчёта приложить **настоящие** скриншоты экрана каталога, пустого состояния, списка желаемого и вывода ESLint. Не указывать вымышленные результаты проверки.
