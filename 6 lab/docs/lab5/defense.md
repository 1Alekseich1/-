# Краткая защита лабораторной №5

**Что такое React?** Библиотека для построения интерфейса из компонентов. Когда состояние меняется, React пересчитывает отображение.

**Зачем TypeScript?** Проверяет типы при сборке, например не даст случайно передать строку вместо числа.

**Что такое props?** Данные, которые родитель передаёт дочернему компоненту. Например, BookCard получает `book` и `saved`.

**Где хранится состояние?** Основное — в App, потому что и каталог, и шапка, и избранное используют его. Параметры поиска передаются в FiltersPanel через props.

**Почему нельзя менять state напрямую?** React должен получить новое значение или массив, поэтому используется setState и операции вроде `filter`, `map` и spread.

**Зачем нужен key?** Для устойчивой идентификации карточек между рендерами. Здесь используется id книги, а не индекс.

**Почему fetch в api/?** Чтобы компоненты занимались только отображением; API можно заменить в одном месте.

**Что такое AbortController?** Средство отменить старый запрос при новом поиске. Не даём устаревшему результату перезаписать новый.

**Зачем localStorage?** Он хранит избранное между перезагрузками браузера.

**Как проверить?** Показать каталог и фильтры, добавление в избранное, обновление страницы, offline-ошибку, React DevTools, затем выполнить `npm run build`.
