# Использование ИИ

При выполнении лабораторной №5 использовался ChatGPT для подготовки исходного кода React/TypeScript, декомпозиции компонентов, поясняющих комментариев и документации. Перед сдачей студент должен самостоятельно запустить приложение, изучить код, провести линтинг, проверить работу в DevTools и уметь объяснить любую его часть.
