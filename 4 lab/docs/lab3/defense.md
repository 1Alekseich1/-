# Защита лабораторной №3

**Как показать:** запусти Live Server → каталог → попробуй поиск «Толстой», жанр «Классика», только доступные и сортировку по рейтингу → сбрось фильтры → добавь две книги → нажми «Мой список» → обнови страницу → удали книгу.

**Что такое `state`?** Один объект, который хранит фильтры и ID книг в избранном. После его изменения вызывается `update()`, сохраняющий данные, а затем `render()`.

**Зачем модули?** `data/books.js` хранит записи; `lib/books.js` содержит чистые функции без DOM; `ui/render.js` рисует HTML; `main.js` связывает события и состояние.

**Зачем `[...]` перед `sort()`?** Метод `sort()` изменяет массив. Копия защищает исходные данные.

**Что такое делегирование?** Обработчик стоит на `main`, а не на каждой кнопке. `event.target` — элемент, по которому кликнули, `closest()` ищет ближайшую подходящую кнопку.

**Для чего `aria-pressed`?** Обозначает выбранное или невыбранное состояние кнопки для вспомогательных технологий.

**Зачем `try/catch`?** `JSON.parse()` может получить некорректную строку из localStorage; тогда используются безопасные значения по умолчанию.

**Почему открывать через Live Server?** ES-модули в некоторых браузерах не работают при открытии страницы по `file://` из-за политики безопасности.
